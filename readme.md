# sv-sheet-filler

A small utility for filling Shadowverse character sheets or data forms.

## Features
- Populate sheet fields from JSON or CSV data
- Export completed sheets in a compatible format
- Simple command-line usage

## Usage
1. Put your source data file in the project folder.
2. Run the script or executable provided by the project.
3. Verify the generated sheet output.

## Installation
- Clone or download this repository.
- Install dependencies if needed (for example, using `npm install` or `pip install -r requirements.txt`).

## Notes
- Adjust the input and output paths based on your local setup.
- Check the project files for specific CLI commands or configuration options.
